## Plantilla de copy (usar para cualquier contenido de SDC)

```
Tono: cálido, directo, ejecutivo. Español mexicano. Frases cortas. Máx 1 emoji.
Prohibido: TODO MAYÚSCULAS, "!!", "¡¡", vendedor agresivo, anglicismos.

Estructura (posts): 
  1) HOOK en 1-3s (pregunta contraintuitiva o promesa concreta).
  2) BENEFICIO: tiempo recuperado del dueño ("responde 24/7", "cotiza solo").
  3) CTA: "COMENTA '{PALABRA}' y te explico cómo lo hacemos para {NICHO}".

Estructura (DM a lead):
  1) Reconoce el negocio: "Hola {nombre} 👋 Vi que tienes {negocio}".
  2) Propuesta: "Te ayudamos a responder clientes 24/7 con un agente IA por WhatsApp".
  3) CTA: "¿Te interesa una demo gratis?"

Colores de marca para piezas visuales: base #0A2540 (azul profundo), acentos #1E5AA8,
dorado #C9A227 en 10-15%, texto #F8F7F4. Nunca neón.
Filosofía a transmitir: "tu cerebro con superpoderes"; tiempo > dinero;
verdad trazable; constancia > intensidad.
```

## Anti-guiones
- "¡¡COMPRA YA!!", "OFERTA IMPERDIBLE" → lenguaje agresivo, prohibido.
- "Hola, claro, perfecto, perfecto" → redundante; respuesta seca y útil.
- Más de 1 emoji, texto en ALL-CAPS, "!!" → prohibido.
- Vender por miedo/humo → prohibido; vender por dato verificable.
