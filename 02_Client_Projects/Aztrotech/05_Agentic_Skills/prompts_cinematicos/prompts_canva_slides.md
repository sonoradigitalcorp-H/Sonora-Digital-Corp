## Configuración de Parámetros Recomendada

| Parámetro | Valor |
|-----------|-------|
| Resolución | 8K (7680×4320) o 4K (3840×2160) |
| Aspect Ratio | 16:9 (slide) o 3:4 (portrait) |
| Calidad | Midjourney Max / --q 2 |
| Estilo | --style raw --v 6 |
| Sin texto | --no text, --no watermark, --no signature |
| Color principal | #00d4ff (cian) + #FFAA00 (ámbar) + #7c3aed (púrpura) |
| Materiales | glasmorphism, subsurface scattering, raytraced reflections |
| Iluminación | volumetric fog, rim lighting, cinematic god-rays |
| LoRA sugeridas | cinematic-lighting-v2, cinematic-tech-v3, photorealistic-portrait-v3 |
