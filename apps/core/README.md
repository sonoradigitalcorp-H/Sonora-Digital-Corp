# core

Motor central de Sonora Digital Corp. Orquestador de agentes, habilidades,
memoria, políticas y comunicación entre servicios.

- **Rol**: Cerebro del sistema — rutero, planificador, ejecutor
- **Stack**: Python, FastAPI, asyncio
- **Puertos**: 8000 (API), 8001 (WS bridge)
- **Dependencias**: Redis, Qdrant, PostgreSQL
