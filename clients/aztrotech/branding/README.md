# Branding — AztroTech

Basado en *Brandbook 2026* de César Holguín.

## Identidad

- **Eslogan**: "Espiritualidad con Estructura"
- **Tagline**: "Su elección impulsa nuestra excelencia"
- **Tono**: Preciso, estratégico y cercano. Experiencia, liderazgo, excelencia.
- **Valores**: Innovación Responsable, Medición, Resultados Verificables
