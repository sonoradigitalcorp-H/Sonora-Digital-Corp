## 🧮 Los Números

### Con 50/50 puro:

```
César factura $1M MXN/mes
──────────────────────────
César:   $500,000 MXN (50%)
SDC:     $500,000 MXN (50%)

César paga $0 de costs de plataforma
SDC paga ~$5,000 MXN de infraestructura
SDC GANANCIA NETA: $495,000 MXN/mes
```

### Vs el modelo que propuse (10% + $25K renta):

```
César factura $1M MXN/mes
──────────────────────────
César:    $875,000 MXN (87.5%)
SDC:      $125,000 MXN (12.5%)

SDC GANANCIA NETA: ~$120,000 MXN/mes
```

### Diferencia:

```
50/50:     SDC gana $495,000 MXN/mes
10%+renta: SDC gana $120,000 MXN/mes
─────────────────────────────────────
DIFERENCIA: $375,000 MXN/mes más con 50/50
```

**Con 50/50, SDC gana 4 VECES MÁS que con el modelo anterior.**

## ✅ Argumentos a FAVOR del 50/50

| Razón | Peso |
|---|---|
| **Escala inmediata** — César ya tiene clientes y facturación | 🔥 |
| **Sin él, no hay revenue** — Tú no tienes acceso a esos clientes | 🔥 |
| **50% de $1M es mejor que 100% de $0** | 🔥 |
| **Alineación total** — Los dos quieren que crezca | ✅ |
| **Sin riesgo de cobro** — Él factura, tú cobras tu mitad | ✅ |
| **Puedes usar su caso de éxito para vender a otros** 🚀 | ✅ |
| **50% de $3M/mes = $1.5M para SDC** | 🔥 |

## ❌ Argumentos en CONTRA del 50/50

| Razón | Peso |
|---|---|
| **Tú pones la tecnología, él pone clientes que ya tenía** | ⚠️ |
| **Si se va, te deja sin ingreso** | 🔴 |
| **50% es mucho si él solo vende y tú construyes** | ⚠️ |
| **¿Qué pasa si él deja de vender? Tú sigues pagando infra** | ⚠️ |
| **El IP es tuyo, la marca es suya — desbalance** | ⚠️ |

## 🎯 Mi Recomendación

### No des 50/50. Da 60/40 o 70/30 con escalera.

```
PROPUESTA: 60/40 (TÚ 60%, CÉSAR 40%)
────────────────────────────────────────

¿Por qué 60% para ti?
  · Tú pones la tecnología (sin ti no hay producto)
  · Tú mantienes, actualizas, soportas
  · Tú tienes el IP (si él se va, el producto se queda contigo)
  · Tú puedes replicar este modelo con otros partners

¿Por qué 40% para él?
  · Él tiene los clientes (sin él no hay revenue inmediato)
  · Él vende, atiende, managea la relación
  · Él tiene presencia local en Hermosillo
  · Él puso su marca en juego

CÉSAR GANA CON 60/40:
  $1M → $400,000 MXN/mes (neto, sin costos)
  $3M → $1,200,000 MXN/mes

SDC GANA CON 60/40:
  $1M → $600,000 MXN/mes
  $3M → $1,800,000 MXN/mes

DIFERENCIA vs 50/50:
  En $1M: solo $100K MXN menos para cada uno
  En $3M: solo $300K MXN menos
  Pero proteges el control del producto
```

### Si él insiste en 50/50, pon estas condiciones:

```
1. MÍNIMO GARANTIZADO
   "50/50 siempre que factures ≥$500K MXN/mes.
    Si facturas menos, la comisión sube a 70/30
    porque yo sigo pagando infraestructura."

2. IP Y PROPIEDAD
   "La plataforma, el código, los agentes son míos.
    Tú tienes licencia exclusiva para tus clientes.
    Pero el producto es de SDC."

3. NO COMPETENCIA
   "Mientras seamos socios, no puedes usar otra
    plataforma para dar el mismo servicio."

4. EXCLUSIVIDAD (opcional)
   "Eres el único partner con 50/50. Los demás
    pagan 30% de revenue share."

5. VESTING
   "50/50 después de 3 meses si cumples metas.
    Los primeros 3 meses es 70/30 (para cubrir
    mi inversión en implementación)."
```

## 📋 El Contrato Verbal

```
" César, te propongo esto:

Yo pongo la tecnología, los agentes, la memoria,
la voz, la infraestructura, el soporte.

Tú pones los clientes, las ventas, la relación local,
tu marca.

Si tú vendes $1M/mes → la plata funciona para los dos.

Pero necesito que entiendas: esto que construí
es mi activo más valioso. No es solo código.
Son años de trabajo, de pruebas, de aprendizaje.

50/50 está bien si:
  · Ambos ponemos algo de valor similar
  · Ambos arriesgamos similar
  · Ambos trabajamos similar

Tú pones clientes. Yo pongo la máquina.
Sin la máquina, no tienes producto.
Sin los clientes, no tienes revenue.

Yo veo justo 60/40 para empezar,
y cuando lleguemos a $2M/mes,
revisamos los términos.

¿Qué te parece?
" 
```

## 💎 Resumen

| Escenario | SDC gana | César gana | Veredicto |
|---|---|---|---|
| 50/50 puro | $500K | $500K | Justo si ambos ponen lo mismo |
| 60/40 | $600K | $400K | **Recomendado** |
| 70/30 | $700K | $300K | Seguro para SDC |
| 10% + renta | $125K | $875K | Mejor para César |

**Mi recomendación: Ofrece 60/40 con escalera a 50/50 cuando lleguen a $2M/mes.**

Así:
- Él se siente motivado a crecer
- Tú proteges tu inversión inicial
- Llegan juntos al 50/50 cuando el pastel sea más grande
