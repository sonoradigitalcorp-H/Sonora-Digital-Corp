# MODELO DE SOCIO FUNDADOR — César / AztroTech

## El Problema

César quiere **unión o fusión** de AztroTech con SDC.
Tú quieres **venderle un servicio**, no regalarlo.

**La solución intermedia:** Socio Fundador con beneficios de co-founder
pero con términos comerciales claros. No es empleado, no es dueño,
es **PARTNER ESTRATÉGICO** con upside ilimitado.

## 2. El Modelo para César como SOCIO FUNDADOR

### Trato: Socio Fundador (no empleado, no dueño, no cliente)

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  CÉSAR PAGA:                                                       │
│  ─────────────────────────────────────────────────                │
│  · Implementación:          $2,500 (una vez, precio fundador)      │
│  · Renta de tenant:         $49/mes (fijo, sin importar clientes)  │
│  · Creación de agente:      $1,000 c/u (precio fundador)           │
│                                                                    │
│  CÉSAR NO PAGA:                                                    │
│  ─────────────────────────────────────────────────                │
│  · Comisión por uso (0% los primeros 6 meses)                      │
│  · Comisión por sub-tenants (0% los primeros 6 meses)              │
│  · Soporte premium (incluido)                                      │
│  · Capacitación a su equipo (incluida)                             │
│                                                                    │
│  CÉSAR GANA:                                                       │
│  ─────────────────────────────────────────────────                │
│  · 100% de lo que cobre a sus clientes (sin comisión SDC)          │
│  · 30% de comisión de referidos (si refiere otros partners)        │
│  · Acceso a beta features (clon digital, agentes custom)           │
│  · Voto en roadmap de producto                                     │
│  · Co-branding: "AztroTech × Sonora Digital Corp"                  │
│                                                                    │
│  SDC GANA:                                                         │
│  ─────────────────────────────────────────────────                │
│  · $2,500 implementación                                           │
│  · $49/mes renta tenant                                            │
│  · $1,000 por agente creado                                        │
│  · Después de 6 meses: 15% comisión sobre ventas de César         │
│  · Después de 12 meses: 10% comisión sobre sub-tenants             │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

### ¿Por qué funciona?

```
Para CÉSAR:
  · Inversión inicial: $3,500 ($2,500 impl + 1 agente)
  · Vende a 5 clientes a $999/mes = $4,995/mes
  · Sus costos: $49 (tenant) + $0 comisión = $49/mes
  · GANANCIA: $4,946/mes → recupera inversión en 1 mes

Para SDC (TÚ):
  · Ingreso inicial: $3,500
  · Ingreso mensual: $49 (podría ser solo esto si César no crece)
  · Pero apuestas a que César crece y después de 6 meses
    empiezas a ganar 15% de sus ventas
  · Si César llega a 50 clientes → $7,500/mes para ti solo de comisión
  · + todos los demás partners que César refiera

El trato es: Tú le das condiciones de fundador al inicio
a cambio de que él construya la red contigo.
Ganas más en volumen que en margen por él.
```

## 4. ¿Fusión o Asociación? — Términos claros

### Lo que NO es:

```
❌ César NO es dueño de SDC
❌ César NO tiene equity
❌ César NO tiene acceso a costos reales
❌ César NO decide sobre otros partners
❌ César NO tiene acceso al código fuente
```

### Lo que SÍ es:

```
✅ César es SOCIO FUNDADOR (primer partner estratégico)
✅ Tiene los mejores términos comerciales
✅ Beneficios de co-founder sin ser dueño
✅ Co-branding: "AztroTech powered by SDC" o "SDC + AztroTech"
✅ Voz en el roadmap (qué construir, para quién)
✅ Él construye su red, tú le das las herramientas
✅ Si la fusión real llega, se negocia en otro nivel
```

### El pitch:

```
"César, no te vendo un servicio. Te invito a ser
el PRIMER SOCIO FUNDADOR de la plataforma.

No te pido equity. No te pido fusión.
Te pido que CONFÍES en que esta tecnología
es el futuro de tu negocio.

Tus clientes van a tener agentes que hablan,
recuerdan, venden y crean contenido.
Tú vas a ganar dinero mientras duermes.

Y cuando estés listo para hablar de fusión real,
lo hacemos como socios, no como cliente y proveedor.

Pero primero: demostremos que esto funciona.
¿Empezamos con 1 agente para tu mejor cliente?"
```

## 5. Proyección a 12 meses con César como Socio Fundador

```
MES 0:
  SDC: +$3,500 (impl + 1 agente)
  César: -$3,500

MES 1-3:
  César vende a 3 clientes ($999 c/u)
  César gana: $2,997 - $49 (tenant) = $2,948/mes
  SDC gana: $49/mes (renta)

MES 4-6:
  César tiene 10 clientes
  César gana: $9,990 - $49 = $9,941/mes
  SDC gana: $49/mes (renta)
  → Fin del periodo de gracia

MES 7-12:
  César tiene 25 clientes
  César gana: $24,975 - $49 - $3,746 (15% SDC) = $21,180/mes
  SDC gana: $49 + $3,746 = $3,795/mes
  + 3 clientes referidos por César (pagan implementación completa)
  → $7,500 × 3 = $22,500 extra para SDC

TOTAL A 12 MESES:
  SDC: $3,500 (inicial) + $588 (renta 12 meses) + $22,482 (comisión mes 7-12)
       + $22,500 (referidos) = $49,070
  César: $153,474 - $3,500 (inversión) = $149,974
```
