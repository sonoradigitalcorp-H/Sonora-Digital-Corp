## 🧠 Los 4 Agentes Core de César

### 1. Soporte Pro — El que LLAMA

```
Personalidad: Empático, resolutivo, paciente.
Capacidades:
  · Recibe llamadas entrantes con voz natural (Kokoro)
  · Clasifica urgencia y deriva si necesario
  · Consulta base de conocimiento (RAG)
  · Abre tickets y da seguimiento
  · Aprende de cada interacción (Engram)
  · Escala a humano si no puede resolver

Tecnología:
  · Wake word + Whisper STT + deepseek + Kokoro TTS
  · Integración con CRM del cliente
  · Memoria persistente por ticket

Para qué cliente: Talleres mecánicos, clínicas, despachos,
servicios técnicos — cualquiera que reciba llamadas 24/7.
```

### 2. Content Engine — El que CREA y PUBLICA

```
Personalidad: Creativo, estratégico, consistente.
Capacidades:
  · Genera contenido escrito para redes (Instagram, LinkedIn, TikTok)
  · Crea imágenes con IA (FAL.ai)
  · Programa publicaciones
  · Mantiene tono y branding del cliente
  · Analiza engagement y ajusta estrategia
  · Posicionamiento de marca personal

Tecnología:
  · deepseek + FAL.ai + Playwright (para publicar)
  · Memoria de tono y estilo por cliente
  · Calendario editorial automático

Para qué cliente: Profesionistas que quieren presencia digital
sin pasar horas creando contenido.
```

### 3. Sales Hunter — El que CIERRA

```
Personalidad: Persuasivo, persistente, estratégico.
Capacidades:
  · Prospecta leads de múltiples fuentes
  · Califica por scoring automático
  · Envía propuestas personalizadas
  · Da seguimiento automático
  · Agenda llamadas de cierre
  · Analiza pipeline y pronostica

Tecnología:
  · deepseek + CRM + WhatsApp/Telegram
  · Browser actions para investigación de leads
  · Memoria de cada interacción con el lead

Para qué cliente: Empresas B2B, consultores, agencias
— cualquiera que venda servicios de alto valor.
```

### 4. Superación Personal — El que ACOMPAÑA

```
Personalidad: Motivador, disciplinado, empático.
Capacidades:
  · Coaching diario personalizado
  · Seguimiento de hábitos y metas
  · Accountability (reporta progreso)
  · Meditaciones guiadas con voz
  · Lectura y análisis de libros
  · Bitácora personal (memoria a largo plazo)

Tecnología:
  · Kokoro TTS (voz cálida y motivacional)
  · Engram para memoria personal profunda
  · deepseek para análisis de progreso
  · Modo "diario" con Whisper para journaling por voz

Para qué cliente: Ejecutivos, emprendedores, anyone
que quiera un coach personal IA 24/7.
```
