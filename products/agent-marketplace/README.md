# Mystic Agent Marketplace

## 🤖 Agentes Inteligentes Listos para Desplegar

Marketplace de agentes autónomos con MCPs incluidos, auto-provisioning con solo email + teléfono, y dashboard CEO en tiempo real.

### Stack
- **Auth**: OAuth 2.0 (Google, GitHub) + JWT
- **Backend**: FastAPI + PostgreSQL + Redis
- **Agentes**: OpenCode ADK + MCP protocol
- **Voz**: Twilio / FreeSWITCH + Telnyx
- **Mensajería**: Telegram API
- **Infra**: Docker Compose → VPS

### Inicio Rápido
```bash
# 1. Registrarse con email + teléfono
# 2. Sistema auto-descubre tu negocio
# 3. Elige tu pack
# 4. Agentes desplegados en <5 min
```
