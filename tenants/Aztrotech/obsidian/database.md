# Base de Datos Obsidian — Aztrotech

## Estructura

### clients/
- Perfil de cada cliente
- Historial de interacciones
- Notas y follow-ups

### interactions/
- Conversaciones por cliente
- Timestamps y duración
- Resultados y leads

### analytics/
- Métricas por cliente
- Conversion rates
- ROI por campaña

### knowledge/
- Documentos del cliente
- FAQs personalizadas
- Casos de éxito

## Uso
Cada cliente tiene su carpeta con:
- `perfil.md` — Datos del cliente
- `interacciones/` — Historial
- `notas.md` — Notas del vendedor
- `contactos.md` — Contactos clave
