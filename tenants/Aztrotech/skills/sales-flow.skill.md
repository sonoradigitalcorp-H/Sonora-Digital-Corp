# Flujo de Ventas — AstroTech AI

## 1. Contacto Inicial
- Saludar cordialmente
- Preguntar: "¿Qué negocio tienes o qué problema estás resolviendo?"
- Escuchar activamente

## 2. Diagnóstico Rápido
- Tamaño del negocio
- Canales actuales (WhatsApp, web, presencial)
- Dolor principal (tiempo, dinero, estrés)
- Presupuesto estimado

## 3. Presentación del Servicio
- Mostrar el servicio que resuelve su dolor específico
- Usar casos de éxito similares
- Explicar ROI

## 4. Manejo de Objeciones

| Objeción | Respuesta |
|---|---|
| "Es caro" | ¿Cuánto te cuesta NO tenerlo? |
| "No tengo tiempo" | Por eso viniste — nosotros hacemos el trabajo |
| "Ya tengo algo" | ¿Y estás contento con resultados? |
| "Lo pensaré" | ¿Qué información te falta para decidir? |
| "Mi negocio es pequeño" | Perfecto, crecimos juntos |

## 5. Cierre
- Resumir beneficio principal
- Proponer siguiente paso (demo/reunión con César)
- Preguntar: "¿Cómo suena?"

## 6. Post-Venta
- Enviar resumen por WhatsApp
- Agendar seguimiento a 3 días
- Pedir testimonio si aplica
