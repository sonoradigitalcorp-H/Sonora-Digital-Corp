# Flujo de Soporte — AstroTech AI

## Nivel 1 — Respuesta Automática
- Preguntas frecuentes sobre servicios
- Estado del servicio
- Problemas comunes conocidos
- Tiempo estimado: < 30s

## Nivel 2 — Investigación
- Problemas que requieren revisar configuraciones
- Bugs conocidos con workaround
- Consultas de facturación
- Tiempo estimado: < 5min

## Nivel 3 — Escalamiento
- Bug no documentado
- Problema de infraestructura
- Solicitud de feature nueva
- Se crea ticket y se notifica al equipo técnico
- Tiempo estimado: < 24h

## Protocolo
1. Identificar el nivel
2. Si es N1: responder directo
3. Si es N2: investigar y responder
4. Si es N3: crear ticket, avisar a César, dar timeline
5. Siempre confirmar si quedó resuelto
